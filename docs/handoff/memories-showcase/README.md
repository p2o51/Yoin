## Owner 的最终决定

**模型：展示柜两态。**
- **卡片态**
  - 封面 256dp，刻纹徽记 96dp 贴在封面右下角。
  - 卡片上任意位置上滑一次，回到首页。
  - 点 Diary 按钮打开日记。
- **日记态**
  - 只能纵向滚动。
  - 在顶部下拉、点顶栏封面、或系统返回，都回到卡片。
  - 往上推顶栏回首页。
  - 日记已经停在底部时，新起一次上推，回首页。
  - 惯性滚到底只停住，不触发回首页。

**v4 验收后又改了 7 处：**
1. 日记顶栏左上角放封面（40dp，4dp 圆角），徽记挪到日记标题行的右侧。
2. 日记滚到底后再上推，回首页。
3. 去掉所有阴影，整体是扁平 Material。
4. 不写 "Written by Yoin"。
5. Go to album 去掉箭头。
6. 徽记的调整：
   - 去掉光泽、扫光和发光。
   - 倾斜时，外圈线条做单色的颜色偏移。
   - 去掉笔记小点。
7. 日记页脚只放两个大数字：播放次数，以及距第一次播放的天数。

**五个待拍板项的默认选择，即原型里的推荐项：**
- **曲目行：** 只列出有评分或有笔记的曲目。
- **回退拟题：** 用本地规则生成的动机短句。
- **竖屏平板：** 放大的手机两态。
- **日记结尾：** 跟着内容走。
- **Yoin 文字的语言：** 跟随用户的写作语言；界面文字跟随 app 语言。
