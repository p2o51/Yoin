## 1. 定稿细则

### 1.1 曲线 C（所有顶部交界）

网点半径（以格距 cell 计）：

```
t      = clamp((d + 前沿起伏) / G, 0, 1)        // d：点中心到交界的距离（dp），交界以下为正
半径   = 0.64 × cell × t^0.8
打旋包络 = sin(πt) × √(1 − t) × D                // 两端为 0；D 是无序度，见 1.7
流动相位 = t + 余韵 / G
d ≥ G + F 直接画实色
前沿起伏 = (bj / 0.22) × F × smoothstep(d / (0.35 G)) × D   // bj 是现有的 bend + jitter，范围约 ±0.22
```

- 去掉现在曲线里的 0.1 偏移：点一直缩到交界线上，末端不再空一段。
- 点半径小于一个设备像素（1/2.75dp）时不画，和现在一样。
- **静紧动松**：G / F / 文字带 T 随滚动速度插值。

| | 静止 | 速度 ≥ 1450dp/s |
| --- | --- | --- |
| 带高 G | 12dp | 34dp |
| 前沿起伏 F | 3dp | 8dp |
| 文字带 T | 10dp | 26dp |

  插值量 `stretch = smoothstep((speed − 150) / 1300)`，150dp/s 以下不伸缩。`speed` 是一个新的一阶跟随者：每帧 `speed += (|Δscroll| / dt − speed) × (1 − e^(−ω dt))`，**和余韵共用 ω = √90**（`YoinMotion.SeamFlowSettleStiffness`），停下后约 0.5 秒收回。
- 余韵不变：落后量封顶 G/2（现在是 0.5 × Band）。
- RevealDistance 不变：前 40dp 滚动里过渡带从 0 长满，静止在顶部时不出现。
- 省电模式和“移除动画”：余韵为 0，stretch 固定为 0。
- 效果：静止时离交界 11dp 以内才出缝（第一版是 31dp），滚动时约 30dp。

### 1.2 底部网点场

**几何**。以屏幕坐标计（原因见 1.5）。设栏的上沿为 `barTop`，栏的圆角矩形为 `barRect`（位置、尺寸、圆角都从 `FloatingBottomBar` 的布局坐标拿）。

```
HIDE  = 28dp                                          // 过渡段藏在栏上沿之后的部分
start = 20dp                                          // 起点：栏上方 20dp（定稿值）
len   = (start + HIDE + 20dp × stretch) × rb          // 过渡段长度；滚得快时最多再往上伸 20dp
yb    = barTop + HIDE                                 // 纯网点从这里开始（在栏后面）
y0    = yb − len                                      // 过渡段的起点
rb    = clamp((列表剩余可滚距离) / 40dp, 0, 1)         // 列表最后 40dp 滚动里过渡段收成 0
```

**点的半径**（`d0 = 点中心的屏幕 y − y0`，k 以格距计）：

```
d0 ≤ 0                 : 实色（整点），但仍要参加下面的让位判断
y < yb（过渡段）        : a = clamp((d0 + 3dp × (bj / 0.22) × smoothstep(d0 / 10dp) × D) / len, 0, 1)
                          k = mix(0.62, k0, smoothstep(a))
                          打旋包络 = sin(πa) × D，流动相位 = 2a + 余韵 / 24dp
y ≥ yb（纯网点）        : k = mix(k0, 0.9 × k0, (y − yb) / (屏幕底 − yb))，不打旋、不流动
k0 = √(覆盖率 × 0.866 / π)，覆盖率 40% → k0 ≈ 0.332
半径 = k × cell
```

- 栏周围和下方是**静止的规则点阵**，只有过渡段在滚动时流动；停下后过渡段也回到格点（D = 0），和栏下面连成同一片，播放控件旁边保持安静。
- 完全被栏盖住的点（到 `barRect` 的有符号距离 < −r − 0.5dp）不画，省事。
- 栏是不透明的，栏上方静止时只看到过渡段刚开始出缝的那 20dp：这里点半径只从 0.62 降到约 0.51 格距，静止时只是一排极小、整齐的针孔，封面看起来是完整的。
- 栏的圆角外侧会露出一点还没碎完的内容，这是预期的。

**退色**：点的颜色越往下越靠近页面背景：`color = mix(content, background, fade(y))`，`fade` 在 y0 处 0，`barTop` 处 0.16，屏幕底边（+20dp）处 0.32，中间线性。**在着色器里做**，这样只作用在图形的点上，文字不受影响。

**按亮度让位**（用户选的方案，替代固定的留白圈）：

```
lum   = L*( 内容在“点的格子中心”的颜色，叠加退色之后 )   // CIELAB L*，0–100
ΔL*   = | lum − L*(栏的容器色) |
need  = 1 − smoothstep(6, 18, ΔL*)                     // ≤ 6 完全让位，≥ 18 不让
dist  = 点中心到 barRect 的有符号距离（dp）
半径 ×= mix(1, smoothstep((dist − 1.5dp) / 7dp), need)  // 让位的点在 1.5dp 内消失，8.5dp 外原大小
```

- **每个点只判断一次**：在格子中心多采样一次内容颜色，整个点共用结果，不会半个点让半个点不让。AGSL 里就是对 `content.eval(cellCenter)` 再采一次。
- 只在 `dist < 8.5dp` 的点上做，别处不花这次采样。
- **还没开始碎的实色内容也要参加判断**：栏边 8.5dp 以内的所有点都要算（原型里称为 guard：`barTop − 8.5dp − 1dp` 以下的行一律逐点计算）。否则起点压得很低时，和栏同色的实色卡片会直接贴在栏上。这是做设计书插图时发现的坑。
- L* 用标准的 sRGB → 线性 → Y → L* 公式；M3 的 HCT 色调就是 L*，所以栏的容器色也可以直接取它的 tone。
- 栏的容器色随动态取色变化，要作为 uniform 传进来。

**栏**：去掉阴影，连同 `BottomBarShadow.kt` 的跨窗口交接一起去掉（先确认没有别的地方依赖它）。

**展开成全屏 Now Playing**：建议在展开开始时把网点场的 reveal 淡到 0，收起后再长回来。这一点用户没细看，做完给他看一眼。

### 1.3 Home 状态栏：潮线

不是着色器，是画在状态栏区域的两条路径，填色就是页面背景（空白处看不见它，只在内容沉下去的地方显出水线）。画在 Home 内容之上、状态栏图标之下。

```
SB    = 状态栏高度（WindowInsets.statusBars 的 top）
rt    = clamp(scroll / 40dp, 0, 1)                    // 前 40dp 滚动里降下来，静止在顶部时藏在屏幕外
A     = 2.4dp + 3.2dp × stretch                       // 振幅随速度，stretch 同 1.1
φ     = (scroll + 余韵) / 88dp                         // 相位跟着滚动走，停下后不动
base  = (SB + 2dp) × rt − 8dp × (1 − rt)

前层：y(x) = base + A × (sin(2π(x/72dp + φ)) + 0.18 × sin(2π(x/36dp − 1.7φ + 0.3)))，不透明
后层：y(x) = base + 6dp + 1.1A × (sin(2π(x/116dp + φ′)) + 0.18 × sin(2π(x/58dp − 1.7φ′ + 0.3)))，φ′ = 0.37 − 0.7φ，55% 不透明
```

- 路径从屏幕上沿（留一点余量）封口到波浪线，先画后层再画前层。
- Home 的图形在顶部**不再**用网点交界，被波浪盖住即可；文字在 `SB + 2dp` 处用 `seamFade` 淡完（文字带和字号规则同 1.4）。
- 省电和“移除动画”：φ 固定为 0，A 固定为 2.4dp。
- 这道波浪和 Now Playing 胶囊里的波浪是同一种线，用户看重这个呼应。

### 1.4 文字

- 透明度曲线：`alpha = 1 − (1 − x′)²`，`x′ = (x − 0.05) / 0.95`，前 5% 为 0（x 是在淡出带里的位置，0 在交界）。
- 淡出长度 = `max(文字带 T, 0.75 × 字号) × reveal`。10dp 的带对正文刚好，对 32sp 的大标题会像被横着切开，按字号放长后约 24dp。
- Home 大标题按文字处理（`seamFade`）。
- **底部不淡出**：文字色和栏的容器色之间本来就有足够对比（onSurface / onSurfaceVariant 是配 surface 这组色调的，栏容器也在其中），所以文字照常从栏后面穿过。顶部仍然淡出，因为顶栏区域和页面同色、是透明的，内容必须在那里消失。

### 1.5 栏两侧和横向列表

- 栏左右两侧那 16dp 属于同一片网点场：碎到什么程度只看屏幕 y，点跟着卡片横向移动，同色的点照样让位，文字被屏幕边切断。
- Home 的 Recently Added 是满宽的 `LazyRow`（`ignoreParentHorizontalPadding` 伸出页边距，屏幕边硬裁，不做边缘淡出，2026-07-18 的决定），而且默认是 Home 的最后一节，经常停在栏边；静止时右边就露着一张专辑卡。
- 所以**几何一律用屏幕坐标**，`seamDissolve` 要挂在 shelf 里的每张卡上（网格卡和专辑卡）。如果只按 LazyColumn 内边距以内的区域算，页边距外那一截会漏掉不碎。

### 1.6 不变的部分

- 网点：约 6dp 错列点阵，锚定在 item 上，颜色就是内容自己的像素，不取色、不染色。
- 图形 / 文字的划分：封面、头像、缩略图、带底色的卡片（底色和封面一起拆点）、评分异形徽章是图形；文字、图标、数字只淡出。
- 余韵模型：一阶跟随者，跟随循环是唯一负责人（中途交给 `Animatable` 会在停下时顿两帧）。
- Library 胶囊下 4dp 固定间距、网格顶部 8dp 内边距。

### 1.7 静整动乱：网点的秩序（第二版新增）

滚动时网点被搅乱，停下后回到格点。凡是不只由位置决定的量，都乘上无序度 D：

```
D        = 1 − e^(−speed / 200dp/s)     // speed 就是 1.1 的速度跟随者（ω = √90），不另起一个
前沿起伏 ×= D                            // bend（每个 item 的弯曲）和 jitter（每个点的抖动）都乘
打旋位移 ×= D                            // 1.1 的 sin(πt)√(1−t) 和 1.2 的 sin(πa)
```

- 点的大小里只由距离决定的部分不受 D 影响。所以静止时每个点都在自己的格点上，大小只由它离交界（或栏）的距离决定，和栏下面的纯网点是同一种规整。
- 速度接近 0 时 D ≈ speed / 200，是线性的，所以停下后 D 和余韵按同一个 e^(−ωt) 衰减，归位和余韵同时结束：从 600dp/s 突然停住，约 0.16 秒过半，0.45 秒内回到格点。速度高时 D 很快饱和：50dp/s → 0.22，200 → 0.63，800 → 0.98（甩起来和上一版一样乱）。
- 范围：所有交界的曲线 C、底部过渡段。栏下面的纯网点本来就不打旋、不流动，不变。切歌时的封面溶解是一次性的转场，本来就一直在动，保持原样；如果它和交界共用 `SeamHalftone.dot()`，给它传 D = 1。
- 速度跟随者在没有新的滚动且 speed < 2dp/s 时归零（原型这样做），D 随之为 0，不会一直差一点点不规整。
- 省电模式和“移除动画”：D = 0，一直规整。
- 用户认可这一版的理由：静止的画面是用来看的，不规整的点像噪点或渲染出错；滚动时同样的不规整读起来是流动。静止时，上一版会在栏上方 20dp 里给封面底边留下零散的白色裂纹，这一版没有。

**保留回退（用户要求）**。上一版就是 D ≡ 1：静止时也打旋、前沿也起伏。做成一个开关，默认是静整动乱：

```kotlin
// ui/theme/Motion.kt，YoinMotion 里
const val SeamSettleAtRest: Boolean = true   // false：回到上一版，D 恒为 1
const val SeamDisorderSpeed: Float = 200f    // dp/s，D = 1 − e^(−speed / SeamDisorderSpeed)
```

- D 只在一个地方算（例如 `seamDisorder(speedDpPerSec: Float): Float`），着色器和 Path 兜底都只读这一个值；开关只改这个函数，不要在多处分支。
- 开关关掉时，省电和“移除动画”下 D 也是 1，和上一版一致（静止时是一个固定的打旋图案，不动）。
- 如果项目里已经有 debug 构建的开发者选项，可以挂一个运行时开关，方便在真机上来回比；那样就把默认值留在 `YoinMotion`，运行时的值从 CompositionLocal 读。没有这类页面就只用常量，不要为此新建页面。

## 2. 实现建议

1. **SeamDissolve.kt 推广**：现在的交界是“viewport 上沿的一条水平线”。需要加一种底部的“场”：viewport 除了上沿，还要知道栏的圆角矩形（屏幕坐标）、栏容器色、列表剩余可滚距离。着色器 uniform 大致是：`barRect`（left, top, right, bottom, radius）、`barLum`、`bgColor`、`start`、`hide`、`k0`、`stretch`、`lag`、`rb`、`guardY`、`disorder`（1.7 的 D，顶部交界也要），以及 item 在屏幕上的偏移。Path 兜底要保持同样的形态（现在两者已经对齐过，照旧截图对比）。
2. **栏的几何**：`FloatingBottomBar` 用 `onGloballyPositioned` 报告自己在窗口里的 bounds，经 CompositionLocal 或状态提供给各页面的 viewport。详情 Activity 的栏同样报告自己的。
3. **数值放哪**：尺寸、阈值进 `SeamDissolveTokens`；速度跟随者复用 `YoinMotion.SeamFlowSettleStiffness`，`SeamDisorderSpeed` 和 `SeamSettleAtRest` 也放 `YoinMotion`，不要在 `ui/` 下直接写 spring 或动画参数（`MotionGuardrailTest`）。
4. **潮线**：Home 屏幕上的一个 `drawWithContent` 或覆盖层，读列表的滚动量、余韵和 stretch（和网点共用同一套跟随者，别另起一套）。
5. **性能**：只有碰到交界或在栏周围的 item 付代价；让位每像素多一次采样，只在栏边 8.5dp 内；潮线是两条路径。静止时零开销。真机（Pixel）上实测帧时间，模拟器数据不作数。

## 3. 接入范围

- **Home**：底部网点场 + 潮线 + 大标题 `seamFade`；Recently Added 的每张卡挂 `seamDissolve`。
- **Library 五个标签**：顶部交界换曲线 C；加底部网点场。
- **详情页**（专辑、艺人、歌单等，栏是从主页接力的）：底部网点场；如果有固定顶栏，顶栏下用曲线 C 的网点。
- 共享组件（`AlbumCard`、`SongListItem`）上已经常驻挂着修饰符，不在 viewport 内时是空操作，照旧。

## 4. 验证

- 用 `LibrarySeamPreviewTest`（`-e captureLibrarySeam true`）的办法逐帧输出，不要逐步截屏再拼视频。给 Home 加一个同类的预览测试，覆盖底部场和潮线。
- 要看的情形：
  1. Library 静止在 60dp：栏上方只有约 20dp 在出缝，栏下是纯网点。
  2. 和栏同色的内容停在栏边：正在播放那张专辑的卡（底座取自同一张封面）在 Recently Added 里，静止时露在栏的右边，应该让开几 dp；深色封面照常贴到栏边。
  3. Recently Added 往左滑 140dp：栏两侧都是网点，跟着卡片横移，不闪。
  4. 列表滚到底：最后一项完整停在栏上方，没有网点。
  5. 快速滚动再停下：顶部溶解带和底部起点一起放宽，约 0.5 秒一起收回，网点同时回到格点；潮线振幅变大再回落。
  6. Home 滚到约 300dp：歌手头像停在时间下面，时间周围是干净的底色。
  7. 深色主题；省电模式；“移除动画”。
  8. 静止时网点规整：Library 静止在 60dp，胶囊下是两行整齐的小点和中点，前沿是直的；一行封面的底边停在栏上方 20dp 里时，只有极小的规则针孔，没有白色裂纹。
  9. 拖着走然后停住（手指不离开屏幕）：约 0.45 秒内点回到格点，和溶解带收紧、余韵结束同时；甩动时点边减速边归位。
  10. 开关关掉（`SeamSettleAtRest = false`）：和上一版一致，静止时也打旋。D 的单元测试两种都要覆盖：开：D(0) = 0、D(200) ≈ 0.632、随速度单调增；关：恒为 1。
- 和设计书里的插图对照（插图由原型同一套渲染代码生成，是准确的参考）。

## 5. 工作约定（沿用 dissolve-design.md 第 7 节）

- 所有改动都还没提交，用户要求**做完再统一拆分和提交**，不要自己拆分、提交或切换分支。注意：那一节写的是 `codex/provider-capability-ui`，现在工作区在 `feat/responsive-breakpoints` 上，改动也在这里。以用户的说法为准，有疑问先问。
- 弹簧和动效参数只在 `ui/theme/Motion.kt` 的 `YoinMotion` 里。
- 模拟器 `emulator-5554` 和别的会话共用，不要改它的全局设置。

## 6. 不要再提

- 盖在交界上的八种（硬截断、透明度渐隐、渐进模糊、整片碎点、顶部网点渗下来、光晕网屏）。
- 在栏前收口的三种（平直收口、贴形绕行、栏后消化）：用户要的是内容延伸到栏下面。
- 固定的留白圈（8dp 空白 + 10dp 渐缩，“太粗”）和 2dp 细白边。
- 状态栏的网点、线网、调频颗粒、流色（平滑版像模糊）；Library 顶栏换潮线。
- 过渡段全放在栏上方（起点 40dp，“太高，影响屏幕利用率”）。

## 7. 写进 design.md 的八条

1. **适用边界**：竖向滚动的内容碰到 Yoin 自己的 chrome 时用网点：Library 的筛选胶囊、详情页的固定顶栏、底部浮动栏。状态栏属于系统，用潮线。横向列表和胶囊行的两端保持现状。
2. **图形和文字**：封面、头像、缩略图、带底色的卡片、评分异形徽章是图形；文字、图标、数字是文字，从不变成点。顶部交界处文字淡出，长度取 max(文字带, 0.75 × 字号)；底部不淡出，照常从栏下穿过。
3. **底部**：图形不在栏前停下：到栏上方 20dp 才开始碎，其余的过渡藏在栏后面完成，栏下面已经是纯网点，一直铺到屏幕底边。栏两侧越过页边距的内容也一样。栏去掉阴影。
4. **状态栏**：用潮线：两道页面底色的波浪，内容沉进水线里，状态栏永远干净。
5. **尺寸**：顶部交界静止时，离交界 11dp 以内才出缝，文字只在最后 10dp 淡出。底部静止时，只在栏上方 20dp 开始碎，其余 28dp 藏在不透明的栏后面。滚动时两处都随速度放宽，停下后收回。
6. **颜色**：网点只用内容自己的像素，只允许向底色靠拢，不引入新颜色、不加光晕。栏和内容不靠阴影分开：亮度和栏接近的点在栏边让位，其余照常。
7. **动效**：溶解程度只由位置、滚动速度和余韵决定。滚动时网点被搅乱，停下后在余韵的半秒里回到格点；静止时每个点都在格点上，完全不动。栏下面的点阵始终不流动。省电模式和“移除动画”下，关掉余韵、随速度伸缩和无序。
8. **性能**：只有碰到交界或在栏周围的 item 重绘，静止时零开销。按亮度让位每个像素多一次采样，只在栏边 8.5dp 以内执行。潮线是一条路径，几乎没有成本。

同时更新 design.md 的 Library 小节和“关键转场动画”表里“Library 列表滚到筛选胶囊下”那一行，加上底部栏和 Home 状态栏两行。
