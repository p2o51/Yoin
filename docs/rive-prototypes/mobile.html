Yoin · 鲲吉祥物落点 (移动端)

同样的弹簧动效,放进真实产品时刻里:开屏、下拉刷新、空状态、AI 加载、点赞反馈、切歌。吉祥物以「app 图标本体」的圆角瓦片出现 —— 一只游动的鲲,身体 + 三片抽象「箭头」鳍各自弹动。既保证对比度,又是「图标活过来了」。点爱心 / 在空状态里移动指针都能交互。

落点优先级。开屏(01)与下拉刷新(02)是最高价值、最低风险的首发位 —— 用户每次进 app 都会看到,且替换的是本就存在的 splash icon / 刷新菊花。空状态(03)与 AI 加载(04)把「等待 / 没内容」的死角变成品牌人格。点赞(05)、切歌(06)是锦上添花的微反馈,且能呼应已有的 NowPlaying aurora 脉冲。落地:每个做成一个 Rive State Machine,导出 .riv,由 rive-android 播放;01–04 用 Rive Elastic 缓动即可,05/06 想随手势速度回弹则把物理放在 Compose spring() 侧。
