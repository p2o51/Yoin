这些动效怎么进到 app。每个原型对应一个用 Rive Editor MCP 编写的 State Machine,导出 .riv,由 rive-android 播放。 ②摸鱼:身体呼吸 + 尾巴摆动用 Rive 循环 timeline(Elastic);两只手「沿曲线抚摸」用 Rive 的 骨骼/Path 约束或把手绑到一条 bone 上,沿身体的引导线往复 —— 想随手势/进度调速就把相位喂一个 number。 ⑥重力:手机端用 SensorManager / TYPE_GRAVITY(或 Compose 的 rememberSensorState)读倾斜,把 x/y 经 androidx.compose.animation.core.spring 平滑后喂 Rive 的两个 number input,每片鳍不同刚度产生拖尾。Kotlin 接缝:vmi.setNumberProperty("tiltX", v)。⑥ 也可和现有 NowPlaying 极光脉冲共用动机。
