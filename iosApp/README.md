# Yoin for iOS (UI skeleton)

SwiftUI, iOS 26, Liquid Glass. Mock data only; no networking. Data sits behind
`MusicLibrary` / `PlaybackSource` (`Yoin/Model/Models.swift`) so the KMP module
can replace `MockLibrary` later.

```bash
brew install xcodegen
cd iosApp && xcodegen generate
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild -project Yoin.xcodeproj -scheme Yoin \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' -derivedDataPath build/dd build
scripts/screenshots.sh <udid> iphone home library album np np-frost landing home-yoinglass "np@yoinglass:-glass yoin"
```

Launch arguments: `-screen home|library|album|np|np-frost|np-panel|landing|home-yoinglass`,
`-npBase flat|frost`, `-glass system|yoin`. In Now Playing, triple-tap the grabber to flip base A/B.

- Icons: Yoin Symbols as custom SF-Symbol templates in `Yoin/YoinSymbols.xcassets`, generated by
  `tools/gen_sfsymbols.py --repo ../yoin-symbols --out <dir> <names…>` (needs `shapely`).
- Fonts: Google Sans Flex 400–700 copied from the Android `res/font`.
- Seek bar: `NowPlaying/WavyProgress.swift` (M3 Expressive wavy indicator port).
- Notes: `docs/ipad.md`, `docs/symbols-ios.md`, `docs/wave-progress.md`.
