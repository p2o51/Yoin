Findings from `iosApp/docs/codex-review.md` are excluded; the rows below identify additional defects or specific gaps introduced by the newer implementations.

## Suspected — not counted as confirmed findings

- **OAuth session lifetime/start failure:** `I/Data/Spotify/SpotifyAuth.swift:213–226` retains no explicit `ASWebAuthenticationSession` reference and ignores `start()`’s Boolean result. Confirm framework lifetime behavior and the failure path before declaring sign-in broken.
- **Stranded connection continuations:** `I/Playback/SpotifyAudioOutput.swift:39–46,70–81` has no timeout/cancellation handling, and `disconnect()` does not finish pending waiters. Whether a waiter remains suspended depends on subsequent SDK callbacks.
- **Island safe-area feedback:** `I/Home/HomeIslandBubble.swift:120` hides the status bar while `I/Home/HomeMemoryBubble.swift:229–246` derives cutout identity from the safe-area top. Check whether supported devices change that inset and repeatedly switch the island branch.
- **Offline encoding compatibility:** `I/Data/Cache/OfflineDownloads.swift:426–432` accepts several original container types, including Ogg, without checking native playback compatibility. Actual supported codec/container combinations need device validation.
